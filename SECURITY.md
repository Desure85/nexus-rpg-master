# Безопасность Nexus RPG

Модель угроз и защиты. Последний аудит — 2026-11-20 (PR «Аудит безопасности»).

## Доступ
- **Партия.** UUID партии — секрет приглашения: по ссылке можно смотреть и играть заявками (с секретом устройства). Менять историю, настройки и экономику может только мастер: автор партии, админ/владелец пространства или суперадмин (`/api/sessions/:id` middleware в `server/api.ts`). Игрокам по ссылке не отдаются доп. инструкции мастера, лор мира и память NPC (`publicSession`).
- **Пространство.** Роли owner > admin > gm; админ не назначает и не снимает владельцев, последний владелец не уходит.
- **Миры.** Правка, хроника, состояние, обложка — только автор; чтение — по доступу мира; платный мир до покупки — витрина без лора; запись хроники меняется только в своём мире.
- **Сокеты.** Подписка на комнату партии по тому же UUID; сообщения до 64 КБ.

## Ввод и вывод
- Текст мастера и игроков выводится через React без HTML: ссылки и картинки из ответа модели не отображаются (нет утечки через markdown-картинки).
- CSP страницы: только свои скрипты, без inline-JS (`server/app.ts`, переопределяется `CSP`).
- Обложки: тип по байтам (JPEG/PNG/WebP), до 400 КБ, отдаются с `nosniff` и `CSP: sandbox`.
- Данные миров нормализуются (`normalizeWorldData`): длины, количества, связи; служебные ключи (`constructor`, `__proto__`) не проходят как id ранга/фракции; состояние героев — объект без прототипа.
- Тело запроса до 2 МБ.

## Деньги и баланс
- Платежи ЮKassa подтверждаются запросом к API ЮKassa (сумма и id платежа), а не телом вебхука.
- Тестовые платежи (`PAYMENTS_PROVIDER=mock`) в продакшене выключены без `ALLOW_MOCK_PAYMENTS=true`.
- Покупка мира — в транзакции, повтор не списывает; доля автору — только с пространств с реальным платежом.
- Потолки хода (`TURN_CAPS`): модель (и инъекции в лор или заявки игроков) не выдаст за ход больше 150 монет и 100 опыта и не нанесёт больше 6 урона.

## Внешние запросы (SSRF)
- Свой URL модели в пространстве (BYOK local, только с `ALLOW_BYOK_CUSTOM_URL=true`) проверяется при сохранении и перед каждым запросом: все IP хоста должны быть публичными (`server/netguard.ts`), редиректы запрещены.

## Вход
- Пароли — scrypt; cookie сессии HttpOnly, SameSite=Lax, Secure за HTTPS; изменяющие запросы требуют заголовок `x-nexus-client` (CSRF).
- OAuth: state + cookie браузера + PKCE; `next` — только путь своего сайта (без `//` и `/\`); почта склеивает аккаунты, только если провайдер её подтвердил.
- Письмо сброса пароля строится только от `APP_URL` (заголовок Host подделывается) — без `APP_URL` письмо не уходит.
- Лимиты частоты: вход и регистрация, ходы, генерация, правки миров.

## Принятые риски
- Ссылка на партию даёт доступ к её тексту — делитесь только с игроками.
- Мастер соло-партии может править свой дашборд (это его игра); на кредиты и маркетплейс это не влияет.
- Купивший мир видит его лор и технически может его переписать и опубликовать — защита через жалобы и модерацию.
